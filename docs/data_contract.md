# Data contract

## Data sources (read by the engine, `FEC_DATA_SOURCE=auto`)

1. `data/processed/analytical_table.csv`: the validated pipeline output (`python analysis/clean_data.py`). One row per (flat, UTC hour) with the 7 channels, price, carbon, occupancy and outdoor temperature. Missing readings are empty (NaN), never 0.
2. `data/processed/clean_readings.csv`: the original long format, kept for compatibility:

| column | type | rule |
|---|---|---|
| flat_id | str | `F001`..`F008` |
| appliance_id | str | `F001-A01` .. `F008-A07` |
| channel | str | `A01`..`A07` (derived from appliance_id if absent) |
| timestamp_utc | ISO 8601 UTC | interval start, `2026-10-01T00:00:00Z` ≤ t < `2026-10-29T00:00:00Z` |
| kwh | float | energy in that hour, **empty/NaN = missing, never 0** |

3. `data/mock/`: generated by `make mock`, used only as a fallback.

`GET /health` reports the source that was used.

### Anomalies are detected by the engine (`core/detect.py`)
`anomalies.json` is no longer read. Each anomaly has:

```json
{"id": "FS-F002-A01", "flat_id": "F002", "appliance_id": "F002-A01", "channel": "A01",
 "type": "fault_step_change", "start": "2026-10-15T00:00:00Z", "end": "2026-10-29T00:00:00Z",
 "status": "PLAUSIBLE", "responsibility": "manager", "confidence": null,
 "excess_kwh": 23.36, "baseline_kwh_per_h": 0.052, "observed_kwh_per_h": 0.122,
 "stats": {"p_value": 0.001, "...": "..."}, "evidence": "free text shown to users"}
```

- `type` ∈ `fault_step_change | base_load_outlier | scheduled_block | heater_pattern | peak_usage`.
- The window is **[start, end)** in UTC.
- `confidence` is always null; status follows the detector's criterion ([claims_and_wording.md](claims_and_wording.md)).
- Internally each anomaly also carries its frozen cells, reference level and cap. These are not serialised.

### cleaning_log.json (optional)
Any JSON; passed through to `/health` → `data_quality.cleaning_log`.

## Finding object (main frontend unit)
Original fields (unchanged names):
`id, flat_id, appliance_id, channel, assumed_type (+ assumed_type_is_assumption), type, title,
status, status_level, wording, responsibility, responsibility_note, window{start,end,days},
evidence{text, confidence (always null), baseline_kwh_per_h, observed_kwh_per_h, reported_excess_kwh},
avoidable_28d{kwh, sek, co2_kg, horizon, scenario, method},
score_if_fixed{apartment{before,after}, resident{before,after}},
projection_annual{kwh|sek|co2_kg: {label:"projection", value|null, low, high, ..., assumptions[]}},
assumptions[], uncertainty{}, verification, simulated`

Additive fields:
- `counts_as`;
- `evidence.statistics` and `evidence.confidence_note`;
- `quantities` (the savings ladder);
- `avoidable_28d.{window_days, label, kind}`;
- `valuation` (SEK by tariff);
- `uncertainty.{sampling_ci95, scenario_range, scenario_method, evidence, not_included}`;
- `tiers{potential, estimated_realized, verified}`.

Changed meaning:
- `avoidable_28d.sek` is SEK **if hourly spot** over the observed window. That window is shorter for a step change.
- `projection_annual.*.value` is null for heating and timing, with a reason.

Full field guide: [api_for_frontend.md](api_for_frontend.md).

## out/ (static fallback, `python -m app.export`)
`scores.json` and `breakdown.json` (keyed by flat), `findings.json` (list), `portfolio.json`, `tips.json` (keyed by flat). Same shapes as the API.
